게시 전 검사

    상태가 "게시"인 튜토리얼만 사이트에 나갑니다. 반영까지 최대 1분.

    버전

    자세한 분석은 Data Studio 대시보드와 Colab 노트북을 쓰세요.

    AI 도우미 (Google AI Studio)

    aistudio.google.com에서 만든 Gemini API 키를 넣습니다. 키는 이 웹앱의 Script Properties에만 저장되고 화면에 다시 보이지 않습니다.

    저장소에서 실습 트랙 가져오기

    GitHub 저장소 content/이름.json 파일의 튜토리얼을 "초안"으로 시트에 넣습니다. 같은 ID가 있으면 덮어씁니다.

    게시 규칙

    켜면 보충 자료 중 권리 확인이 남은 항목은 사이트에서 빠집니다.

    권한 안내

    • 운영자: 40_게시본 폴더 편집자(또는 소유자)
    • 편집자: 원본 시트 편집자 + 00·20·30 폴더 편집자
    • 검수자: 원본 시트 댓글 작성자 또는 뷰어
    • 권한 변경은 Drive 공유 화면에서 합니다.
