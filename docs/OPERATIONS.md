## 자주 하는 일

### 학습자 추가
1. 관리자 → **학습자** 탭 → 이메일을 쉼표나 줄바꿈으로 적고 **추가** (운영자만).
2. 5분 안에 사이트 전체가 열립니다.
3. Classroom 명단 가져오기는 개인 계정 수업에서는 학생 이메일이 안 보일 수 있습니다. 그때는 직접 적습니다.

### 편집자·검수자 추가 (권한 = Drive 공유)
| 역할 | Drive에서 줄 권한 |
|---|---|
| 운영자 | `40_게시본` 폴더 편집자 |
| 편집자 | `00_관리`, `20_미디어_초안`, `30_자료` 폴더 편집자 |
| 검수자 | 원본 시트 댓글 작성자 |

처음 관리자 웹앱을 여는 사람은 "확인되지 않은 앱" 경고가 뜹니다. **고급 → 한걸음서재 관리자(으)로 이동 → 허용**을 누르면 됩니다(본인 권한으로만 동작).

### 그림·GIF 넣기 (두 가지 방법)
- 관리자 단계 카드의 점선 상자에 끌어다 놓기: PNG·JPG는 워터마크가 자동으로 들어갑니다.
- Drive `20_미디어_초안` 폴더에 파일을 넣고 → 관리자 **미디어** 탭 → **Drive 폴더에서 가져오기** → 대체 텍스트 입력 → 단계의 **미디어 ID** 칸에 ID 붙여넣기.
- 게시할 때 쓰인 파일만 `10_미디어_공개`로 옮겨지고 링크 공개가 됩니다. GIF는 움직임이 그대로 유지됩니다(2026-10-19 확인).

### 게시와 되돌리기
- 상태가 "게시"인 튜토리얼만 사이트에 나갑니다. 편집자는 "검수중"까지 정합니다.
- **게시** 탭 → 검사하기 → 게시하기. 1분 안에 반영됩니다.
- 문제가 생기면 버전 표의 **되돌리기**.

### 원문(lessons·supplements·책) 고치기
원문은 Drive `50_원문` 폴더에 있고 사이트는 이 파일을 그대로 보여 줍니다. 로컬 미러에서 고친 뒤
`node tools/drive-setup.mjs ..\_gated ..\_build\sheet.xlsx ..\_build\drive-state.json` 을 실행하면 바뀐 파일만 갱신됩니다.
