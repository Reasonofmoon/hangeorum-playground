    현재 행동을 수행하고 확인하세요.

    직접 만드는 작업 공간

    조건 카드

    제공된 가상 내용으로 연습하세요. 입력과 실습 상태는 이 브라우저의 v7 저장소에 남아 같은 환경에서 이어할 수 있습니다.

    제공된 HTML 요소만 미리볼 수 있습니다. CSS·JavaScript·외부 URL 실행은 지원하지 않습니다. 코드 편집 → 앱 안 저장 → 미리보기 새로고침 순서로 진행합니다.

    오류 실험 · WB14–WB17

    안내 조건을 완성한 뒤 제목의 닫는 태그 한 곳을 바꿉니다.

    저장한 내용의 미리보기

    문서 제목아직 새로고침하지 않았습니다

    위 제목 표시는 미리보기 문서의 title입니다. 실습실 자체의 브라우저 탭 제목은 바뀌지 않습니다.

    설명의 의미는 자동 채점하지 않습니다. 입력은 이 브라우저의 v7 실습 저장소에 보관합니다.

    저장과 새로고침 후 결과를 확인하세요.

      정답과 비교

      열면 해당 과제의 ‘정답 참조 수행’으로 기록합니다. 정답은 편집칸에 자동으로 들어가지 않습니다.

      
      
      
    
      
    
      개념 확인
      문항에 답한 뒤 설명과 비교하세요.
      
    
      결과와 도움을 함께 기록
      수행 기록
      기록의 ‘이전 통과’는 과거 확인 이력입니다. 현재 코드의 완료 상태나 실제 기기 작업을 보증하지 않습니다.
      
    
      이 앱은 로그인·결제·출판 제출·공개 배포를 수행하지 않습니다. 코드·설명·앱 안 저장본·미리보기·미션·확인 이력을 이 브라우저의 localStorage(v7 웹 실습)에 저장합니다. 같은 브라우저에서 이어할 수 있습니다. 플레이그라운드 초기화는 이 실습 저장만 지우며 다른 실습이나 v6 기록은 지우지 않습니다.
