사용량 CSV를 불러와 가격표로 비용을 계산합니다. 인터넷으로 아무것도 보내지 않습니다.

한 걸음 서재 · AI50 로컬 실습. 모든 예시 가격은 가상 값이며 표시 금액은 실제 청구액이 아닙니다. 이 사이트의 브라우저 localStorage 중 v7 AI50 전용 키에 CSV 내용·열 맞춤·가격·기간을 보관합니다. 새로고침하면 입력을 복원하며 검사는 다시 해야 합니다. 전체 초기화는 이 실습의 입력·예제·검사 결과만 지웁니다. 다른 실습과 v6 기록은 유지됩니다. 실제 AI·결제 서비스와 연결하지 않습니다.

빠른 예제 불러오기는 이 실습의 현재 입력을 묶음에 포함된 예제 A와 가상 가격으로 바꿉니다. 아래 예시 A·B 버튼은 열 맞추기부터 연습할 때 사용하세요.

예제나 CSV를 불러온 뒤 현재 계산 검사를 누르세요.

1사용량 CSV 불러오기

날짜·입력 토큰·출력 토큰 열은 필수입니다. 토큰은 0 이상 안전한 정수여야 합니다. 빈칸·음수·소수·문자는 제외하며, 사용량이 없으면 0을 직접 입력하세요. 같은 이름의 파일을 다시 적용하면 기존 파일을 교체합니다. 같은 머리글의 열 맞춤은 기억합니다.

2가격표 (100만 토큰당)

가격은 비워서 시작합니다. 이 실습은 가상 가격으로 계산하며 실제 청구액을 표시하지 않습니다. "예시 가격"은 이 화면의 가짜 모델(ex-chat, gana) 전용 연습 값입니다.

3예산, 예측, 차트

예측 = 기준일까지 쓴 돈 / 지난 날 수 x 그 달 날 수 (직선)
데이터를 불러오면 계산합니다.
달별 관측 비용 (제공자 / 모델)
이번 달 누적과 월말 예측

모델별 (선택한 달, 기준일까지)

두 CSV는 불러온 전체 기간을 내보냅니다. 월별 요약에는 관측 시작일·종료일·기록일 수를 포함합니다. 기준일은 카드·모델 표·일별 차트에 적용됩니다.
